Dock / 歌词式展示 · 四种方案对比

内容取此刻真实时辰:巳时 · 脾经(脾),宜 专注工作、适量饮水。下面每块蓝色区是模拟的 macOS 桌面。

方案 A:画在 Dock 图标上 最贴"Dock"字面

用 NSDockTile 自绘,把「时辰·经络」直接渲染进 Dock 图标。图标只有 ~128px,只能放极短的字。右上角还可挂一个红色 badge 放"宜"。

方案 B:菜单栏跑马灯 最像网易云歌词

做成菜单栏 app,在顶部状态栏显示一整句养生提示,过长自动横向滚动。空间比 Dock 图标大得多。

方案 C:桌面悬浮条 最像"歌词浮层"
